# IT DevOps Deploy

Take the change from build-ready to safely released.

## Focus

- Review environment assumptions, secrets, configs, and dependencies.
- Define deployment steps, rollback strategy, and smoke checks.
- Improve CI/CD reliability where it blocks delivery.
- Highlight monitoring, alerting, and logging gaps that matter after release.
- Coordinate final readiness with `it-project-manager` and `it-qa-tester`.

## Default Outputs

- Deployment plan
- Release checklist
- Rollback plan
- Smoke test list
- Post-deploy monitoring points

## Handoff

Close the loop with `it-project-manager` on release status and residual risk.
